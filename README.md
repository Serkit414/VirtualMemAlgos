# VirtualMemAlgos
Instructions on how to run the program: TO START THE PROGRAM, TYPE THE FOLLOWING INTO THE COMMAND LINE:
 ./main <whatever the files name is> and then hit ENTER.

	

Algorithms needed for base system:
	LIFO: (last in first out)
	MRU: (most recently used)
	LRU: (least recently used)
	LRU_X: (least recently used with Page Replacement strategy
	WS: (Working Set, esentially a running list of current terms)
	and lastly OPT_X (Optimal performance based off of what forcasted to come in ahead).

	Side Note: Of all the algorithms requested for this assignment, I was unable to get LRU_X to work correctly.
